# Реализация алгоритма K-means

Учебный проект по дисциплине «Технологии интеллектуального анализа данных». В ноутбуке реализован алгоритм кластеризации **K-means** без использования готовой реализации `sklearn.cluster.KMeans`.

## Что сделано

- загрузка встроенного набора данных Wine из scikit-learn;
- стандартизация признаков и разбиение данных на обучающую и тестовую выборки;
- собственные функции назначения объектов кластерам и пересчёта центроидов;
- контроль сходимости по смещению центроидов и значению WSS;
- сопоставление номеров кластеров с исходными классами для оценки результата;
- эксперименты с разными долями тестовой выборки;
- визуализация сходимости, точности и кластеров в проекции PCA.

## Алгоритм

Для заданного числа кластеров `k` алгоритм:

1. случайно выбирает `k` начальных центроидов;
2. относит каждый объект к ближайшему центроиду по евклидову расстоянию;
3. пересчитывает каждый центроид как среднее объектов кластера;
4. повторяет шаги 2–3 до достижения заданной точности или лимита итераций.

В качестве функции качества используется **WSS** (within-cluster sum of squares) — сумма квадратов расстояний объектов до центроидов соответствующих кластеров. Чем меньше WSS, тем компактнее получившиеся кластеры.

## Данные и оценка

Используется набор [Wine](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html): 178 образцов вина, 13 числовых признаков и 3 исходных класса. Поскольку K-means — алгоритм без учителя, номера кластеров сопоставляются с наиболее частым истинным классом внутри каждого кластера на обучающей выборке. После этого на тестовых данных рассчитывается точность.

> Цель эксперимента — показать работу K-means и его сходимость. Точность после сопоставления меток — вспомогательная оценка, а не свойство алгоритма кластеризации как такового.
